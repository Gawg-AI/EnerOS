## 密钥域与记录内容

- 制造记录仅存 `key_domain` = 站端公钥 SHA-256 前 16 hex（可追溯不泄密；
  私钥永不出 KMS/工位机——47.3 出仓纪律延续）。
- 字段：serial / image_sha256 / points_sha256 / key_domain /
  bootctrl_genesis / readback_verified / station_id / provisioned_at_unix
  / result / signature_hex（Ed25519 over canonical JSON）。
- **每设备独立身份密钥注入面 = owner/KMS 后续项**（50 卷如实登记；
  v1.0 信任锚经签名 config bundle 承载）。
