## 实弹修复实录（根因 → 修复）

1. **init bundle 击穿 DTB 窗**（DT_LAYOUT fail-closed REJECT）：bundle
   3108616→3243848B，4MiB 映射窗 DTB 余量不足 → 按 39 卷先例扩窗
   8MiB（kernel patch b_pt2/b_pt3/n+=4 + boot_protocol WINDOW_LEN +
   root-task 窗口测试样本同步）。
2. **svc-config 整包拒载**（unconsumed-config:ai-peer）：registry 双向
   完备性要求 bundle 每条目有注册 consumer → AiPeerConsumer 注册 +
   测试夹具补 ai-peer 条目。
3. **broker SUBACK 漏回显 packet id**：客户端同步等确认超时无限重发
   订阅 → 修 broker（独立软件缺陷）。
4. **应答投递延迟 > 超时**：EXECUTE 周期节拍下 5s 缺省必超时 → 演示
   配置 30s（可配判据）+ 插件 outbox 每轮排空。
5. **相位编排竞态**（peer 未连/未启动）：bash sleep/pkill 子壳 → python
   subprocess 编排器 + peer 连接重试。
6. 上卷遗留：48 协议 4 配置缺 typed compiler 键表登记 → config compile
   构建阻断 → protocol.rs 补 4 键表（generic KV 编译器即插即用）。
