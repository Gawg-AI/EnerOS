# WP-47.6 recovery 诊断探针修复

> 状态：**Accepted**（2026-08-21）· 版本：0.313.22 · commit：见文末
> 蓝图：47-控制写闭环与安全收口蓝图.md WP-47.6

## 目标

- `DefaultProbe` 恒 ok（storage/network 恒 true、temperature 25.0 占位）→
  **真实探针集**（分区表 CRC、镜像 digest、bootctrl 副本一致性、关键服务
  readiness）；**无证据不得报 ok**（每探针输出依据，fail-closed）。

## 代码改动

`crates/security/recovery/src/diag.rs`：

| 项 | 说明 |
|---|---|
| `ProbeVerdict` | 新增——`{ ok, detail }`（detail ≤160B，截断不 panic；`ok:` / `no-evidence:` 前缀 = 输出依据） |
| `PlatformIntegrity` trait | 新增事实源注入面：分区表实测/期望摘要、bootctrl 双副本字节、镜像实测/期望 digest、服务 readiness 标志（`None` = 证据不可得） |
| `SystemIntegrityProbe` trait + `RealIntegrityProbe<S>` | 四探针：`partition_table_crc` / `image_digest` / `bootctrl_copies` / `service_readiness`——**实际比对**；源缺失/读取失败 → fail |
| `NoEvidenceIntegrity` | 默认源（全 `None`）→ 每探针无证据非 ok（fail-closed） |
| `DefaultProbe` | 保留为 D7 测试占位（文档明示生产须注入真实探针）；真实路径 = `RealIntegrityProbe` |
| 测试 | +4（无证据全 fail / 全证据一致 ok / 各类 mismatch fail 带依据 / 局部源缺失隔离判定） |
