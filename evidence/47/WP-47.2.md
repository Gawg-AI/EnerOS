# WP-47.2 点表注册表替换硬编码

> 状态：**Accepted**（2026-08-21）· 版本：0.313.18 · commit：见文末
> 蓝图：47-控制写闭环与安全收口蓝图.md WP-47.2

## 目标

- `PROD_DEVICE_ID=1`/`PROD_POINT_ID=10` 硬编码 → 45 卷点表
  （device_id/point_id 由配置绑定）；
- `PROD_KEY` 退休（grep 旧常量串全仓零命中，含测试）；
- DoD：改点表 → 写目标变（QEMU 证据见卷 Exit Gate）。

## 代码改动（文件清单）

| 文件 | 改动 |
|---|---|
| `configs/points.toml` | **新增 Control 点**：point_id=10 / device_id=1 / modbus-tcp / reg 0x0200 / func 3 / `data_type="control"` / scale 1.0 / ±500kW——写目标由点表唯一确定 |
| `crates/runtime/config-bundle/src/points.rs` | `PointsTable::control_binding()`——首个 `Control` 且设备非 0 的点 `(device_id, point_id)`；无控制点 → None（fail-closed）；+单测（含无 Control 点负例） |
| `crates/agents/control-services/src/cfg_bindings.rs` | **新增**：`fetch_control_binding()`——svc-config `ConfigGet("points")` → canonical 解码 → 控制点绑定（与 svc-modbus-tcp 同 wire 先例）；任一步失败 → None |
| `crates/agents/control-services/src/dispatch_service.rs` | `PROD_KEY` 退休 → `ASSEMBLY_TEST_KEY`（qemu-test 测试键，引用值语义零依赖；47.3 注入链替换）；`PROD_DEVICE_ID`/`PROD_POINT_ID` 常量删除 → `prod_policy(device, point)`/`prod_safety_points(device, point)`/`prod_chain(key, device, point, now)` 全参数化 |
| `bin/svc-control-dispatch.rs` | 装配期经 svc-config（槽 base+3，新 grant）取控制绑定 → engine device/point；绑定缺失 → 0/0 fail-closed（全部拒绝） |
| `bin/svc-device-agent.rs` | 同源取绑定（槽 base+0，新 grant）→ EnvelopeIngress key/lease/scope/policy/safety 全参数化；缺失 → 0/0 default-deny |
| `crates/runtime/root-task/src/spawn.rs` | EIPC_GRANTS += `(svc-control-dispatch→svc-config)`、`(svc-device-agent→svc-config)` |
| `bin/svc-modbus-tcp.rs` | `collect_and_report` 遥测过滤：仅 analog/digital 入采集——Control/Setpoint/Counter 点不污染遥测链（新增控制点不破坏 45 采集链路评估器） |
