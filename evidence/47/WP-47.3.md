# WP-47.3 密钥注入链与私钥出仓

> 状态：**Accepted**（2026-08-21）· 版本：0.313.19 · commit：见文末
> 蓝图：47-控制写闭环与安全收口蓝图.md WP-47.3

## 目标

- 密钥值不落仓不落源码：构建期从显式注入面（`--sign-key` / `ENEROS_SIGN_KEY` /
  `ENEROS_IMAGE_SIGNING_KEY` / KMS_DIR）读入；release/生产装配无键构建
  **fail-closed**；qemu-test 用登记过的测试键。
- **私钥出仓**：`dev-signing.key` / `uefi-test.key/pem` 移入
  `product/security/keys-local/`（gitignore）+ 提供生成脚本；xtask 默认
  引用全部改显式；证据链验签支持独立公钥注入（验签钥与签章钥分离）。
- `key-policy.json` 的 `private_keys_in_repository:false` 从此为真
  （A6 锚点修订：键本就未入库，47.3 处置「默认引用」）。

## 代码改动（文件清单）

| 文件 | 改动 |
|---|---|
| `xtask/src/keys.rs` | **新增**——键解析唯一入口：`resolve_signing_key`（显式 > 环境变量 > 测试键；`ProfileKind::Production` 无键 → Err fail-closed）、`load_signing_key_bytes`、`verify_public_key`（`ENEROS_VERIFY_PUBLIC_KEY` 32B hex 独立注入，缺省由测试键派生）、`test_keys_present`；路径常量全部指向 `keys-local/`；+2 单测（生产 fail-closed / 测试键缺失显式失败） |
| `xtask/src/catalog.rs` | `load_signing_key(root)` → 参数化；`catalog sign [--sign-key <path>]` 显式键；`verify_asset_signature` 改用独立验签钥 |
| `xtask/src/evidence_chain.rs` | 验签（477）→ `keys::verify_public_key`（独立注入）；自动签章（613）→ 仅显式/测试键可解析时（生产无键保持 signature 空，登记不武断） |
| `xtask/src/image_factory.rs` | `env_key_file` 去掉仓库默认路径兜底 → Production fail-closed；qemu-prod 装配面必须显式注入 |
| `xtask/src/flasher.rs` | `DEV_SIGNING_KEY_REL` → `keys::DEV_SIGNING_KEY_REL`（keys-local）；key_ref 构造同源 |
| `xtask/src/gate.rs` | **新增 `qa gate keys`**：①键文件零 git 跟踪 ②源码零默认引用 ③测试键就位（否则显式失败）④生产注入面 fail-closed 登记 |
| `xtask/src/qa.rs` | --sign-key 错误消息更新（keys-local / KMS_DIR 面） |
| `crates/runtime/root-task/src/service.rs` | OTA 探针签章键 → 命名常量 `OTA_PROBE_TEST_SEED = [0x41; 32]`（qemu-test 测试键；release 由 KMS 注入面提供，xtask keys 门禁 fail-closed） |
| `product/security/keys-local/` | **键文件迁移**（dev-signing.key / uefi-test.key / uefi-test.pem；字节不变） |
| `.gitignore` | + `product/security/keys-local/` 白名单目录 |
| `tools/gen-local-keys.sh` | **新增**——本地测试键生成（Ed25519 32B + RSA-3072 UEFI 测试键）；生产键 = HSM/离线仪式 |
