## 2. 实施内容（文件清单内逐项）

### 2.1 `crates/protocols/protocol-abstract/src/address.rs`
`ProtocolAddress` 新增两变体（**恰两变体**，45 红线）：
- `Mqtt { topic: alloc::string::String }`（订阅 topic）
- `Mms { object_ref: alloc::string::String }`（IEC61850 对象引用路径）
派生维持 `Debug/Clone/PartialEq/Eq`。新增单测 2 条（构造/比较/克隆 + 变体互斥）。

### 2.2 `crates/runtime/config-bundle/`（新增 points typed parser）
- `src/schema.rs` → `pub mod points`：`CONFIG_ID="points"`、`FIELD_POINTS=1`、`MAX_POINTS=1024`、`MAX_PERIOD_MS=3_600_000`、`DEFAULT_PERIOD_MS=1_000`、`MAX_ADDR_LEN=256`、协议判别码 `PROTO_*`（1..=7）——自描述子格式布局（count u32 LE + 每条点记录）在模块注释单一事实。
- `src/points.rs`（新）——target 解码面（no_std + alloc）：
  - `PointProtocol`（7 值路由枚举；`from_tag/from_name/tag/plugin_id`）；
  - `PointRecord { point_id, device_id, protocol, addr: Option<ProtocolAddress>, data_type: PointType, scale, offset, period_ms, deadband, range }` + `to_mapping()`（**复用 `ProtocolPointMapping`**，地址型点生成映射；goose/sv 订阅点 → None，45.4 按数据集绑定）；
  - `PointsTable`（`find/by_protocol/len`）；
  - `decode_points_table`（子格式严格解码）+ `decode_points`（canonical payload 完整解码）——拒绝：截断、未知协议判别码、地址长度不符、重复 point_id、scale=0、period 越界、range 非有限/min>max、尾随字节；
  - `PointsConsumer`（TypedConfigConsumer；`Config = PointsTable`）——svc-config 注册。
- `src/toml_compile.rs` → `compile_points`（host 编译面，feature `compile`）：
  - 字段封闭：每点只允许 `point_id/device_id/protocol/addr/data_type/scale/offset/period_ms/deadband/min/max`，未知键 → `UnknownKey`；
  - 不变量：point_id 全表唯一（→ `DuplicateField`）、scale 禁 0、offset 必填、period_ms ∈ 1..=MAX（缺省 1000）、min/max 成对且 min≤max、data_type 名精确匹配 `PointType`（analog/digital/control/setpoint/counter，**禁 "float"/"int"/"bool" 同义词**）；
  - 地址按 protocol 直映：modbus→`addr.modbus{slave_addr,reg_addr,func_code}`、iec104→`addr.iec104{common_addr,ioa,type_id}`、mqtt→`addr.mqtt{topic}`、mms→`addr.mms{object_ref}`；goose/sv 订阅型**不写 addr**（写了 → 错误）；`addr` 表只允许协议对应单一子键。
  - `compile_by_id` 增 `points::CONFIG_ID` 分派。
- `src/lib.rs` → `pub mod points;`；`Cargo.toml` 增依赖 `eneros-protocol-abstract` + `eneros-upa-model`（no_std，点模型仍 upa-model 唯一）。
