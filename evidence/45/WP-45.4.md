## 1. 实施内容

### 1.1 seam 扩展（`protocol-abstract`）
- `PointRegistry` 增对象安全枚举：`len()` + `collect_ids(&mut Vec<PointId>)`（45.4 插件 start 取用点表驱动路由；插件不自造地址）。
- `VecPointRegistry`（具体实现：`Vec<ProtocolPointMapping>` + `BTreeMap<PointId, usize>` 索引，支持 resolve + 枚举）。
- `PointRead { raw, ok, seq }`（单点读取结果；raw → 上层 `to_engineering` + 质量位映射，45.2 消费）。
- `ProtocolPlugin::read_point(now_ms, mapping)` — 默认 = `Unsupported`（诚实：协议 I/O 未覆写不伪造读数）。
- `count_matching_mappings(points, pred)` — 点表消费辅助（改名前 `count_matching_points` 含 `_points` 字面，违反 Exit grep，更名）。

### 1.2 7 处 `_points` 接线（全部消灭 + start 消费）
| 插件 | 消费（start） | read_point |
|---|---|---|
| modbus-rtu | `count_matching_mappings` 统计 Modbus 可寻址点 | 默认 Unsupported（46 适配器真读） |
| modbus-tcp | 统计 Modbus 可寻址点 | **打样真读**：func 3/4 读保持/输入寄存器 1 字（`adapter.read_raw` 新增），线圈/多字 → Unsupported |
| iec104-master | 统计 Iec104 可寻址点 | 默认 Unsupported |
| mms | 统计 Mms 可寻址点 | 默认 Unsupported |
| mqtt | 统计 Mqtt 可寻址点 | 默认 Unsupported |
| goose/sv | 统计全部注入点（订阅型，服务层按协议过滤） | 默认 Unsupported |

每处登记 `routed_count` 字段 + 公开 getter（可观测；避免 dead_code）。地址不兼容点（其他协议）跳过不阻断装配。

### 1.3 modbus-tcp 打样
- `adapter.rs` 新增 `read_raw(reg_addr, func_code, words)`：func 3→保持 / func 4→输入，真读。
- `plugin.rs` `read_point`：按映射地址路由 → 真读 → `PointRead{raw: 寄存器值, ok, seq}`。
- 正负例测试 3 条（见 DoD）。
