## 设计决策（登记）

1. **compatible 约定**（仓库无先例，本 WP 定义，真机 dts 填空项引用）：
   - CAN：`nxp,sja1000`（SJA1000 标准 compatible）
   - RS485：`eneros,rs485-uart`（自定义；驱动后端为 PL011 硬件，但语义是 RS485 端口）
2. **DTB 装配链**：boot-manager 把 UEFI 配置表 DTB 拷贝到 `ENEROS_DTB_PHYS=0x4210_0000`（位于内核 BOOT-007 映射窗口 [0x42000000, 0x42200000) 内，与 init bundle 同模式）；长度上限 1MiB + bundle 长度检查，超限 fail-closed。root-task 从固定物理地址读 FDT 头（magic+totalsize）→ parse_fdt → DeviceInventory。
3. **DIF-27.2-1**：验收口径"ProbeReport 与 configs/qemu-virt.dts 节点一致"——root-task 消费的是**运行时 UEFI DTB**（QEMU 真实 DTB，含 virtio-mmio/rtc 等超集节点），configs/qemu-virt.dts 为其子集；一致性解读 = 报告覆盖 dts 全部节点且状态如实，多余节点如实列出。
4. **指标载体**：root-task 无 metrics crate；ProbeReport 输出结构化 `ENEROS stage=probe-report` 日志行（bound/unbound/failed 数值字段）作为指标。

## 差异登记（补充，QEMU 活体验证后）

- **DIF-27.2-1**：root-task 消费**运行时 UEFI DTB**（QEMU 真实 DTB，56 节点含
  virtio-mmio/pl031/pl061/pcie 等超集），configs/qemu-virt.dts 为其子集；
  一致性 = 报告覆盖 dts 全部设备节点且状态如实（pl011/timer ✓）。
- **DIF-27.2-2**：configs/qemu-virt.dts 的 `arm,gic-v3` 与 harness 实际运行参数
  `virt,gic-version=2` 不符——QEMU 运行时 GIC 节点为
  `intc@8000000`（compatible `arm,cortex-a15-gic`，附 v2m `arm,gic-v2m-frame`）。
  报告以**实际节点**为准（intc@8000000 如实列出）。
- **DIF-27.2-3**：DTB 装配位置为**动态**（bundle 后页对齐，`dtb_window_for`），
  非固定常量——QEMU 实测运行时 DTB 1 MiB + 4 KiB 使固定 1 MiB 上限方案
  失败（NO_DEVICE_TREE → DT_LAYOUT 演进）。
