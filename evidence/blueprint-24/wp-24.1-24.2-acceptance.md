## WP-24.2 适配器迁移

### 验收 1：三个 master 适配器契约全绿（含篡改/不匹配用例）
```bash
cargo test -p eneros-modbus-rtu     # 77+2+1 passed（含契约套件）
cargo test -p eneros-modbus-tcp     # 58+1 passed（含契约套件）
cargo test -p eneros-iec104-master  # 59+1 passed（含契约套件）
```
三个适配器均在 `write_authorized` 中实现：设备 ID 匹配 → 点映射匹配 →

落写；不匹配返回 `CommandMismatch` 且设备状态不变（契约以落写后回读基线
断言状态不变，零容差）。回读确认：协议应答即确认（`echoed: None`，§6.1 可空语义）。
