## 三、验收证据

### 验收 1：第二层收口测试全量（真 HMAC 密钥，禁 mock 验签）
```bash
cargo test -p eneros-device-agent     # 37 passed（含第二层 10 用例 + 装配演示 + 既有 26）
```
第二层用例（`ingress.rs` tests，全部经真实 `ControlChain` 复验路径）：
1. 有效信封落写（含回读一致）+ write_allowed + 审计 ✓
2. 篡改信封拒（HMAC）+ write_denied_hmac + 设备状态不变 + 审计留痕 ✓
3. 过期信封拒（时间性 → lease 桶）✓
4. 吊销租约拒（立即生效，墓碑）✓
5. stale token 拒（fencing 单调性）✓
6. 幂等重放返回先前结果，不二次执行（值保持 50.0）✓
7. 设备/点不匹配拒（路由层）✓
8. 协议写失败（离线设备）→ failed_protocol，跳过本条 ✓
9. 握手返回 {lease_id, token} 且 HMAC 保护（篡改/错钥验证失败）；token = epoch_seed+1 ✓
10. 重启计数种子单调性（重启后旧 token 为 stale）✓
