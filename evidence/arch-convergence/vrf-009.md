# VRF-009：冻结硬件专属规格（S5，不实测）

按任务规则：硬件专属规格**定义并冻结**，不实测（缺硬件 BLOCKED）。

## 1. HIL 机架规格（冻结）

- **被测对象**：D2000 单板（8 核 Cortex-A72 级，见 BSP-001）+ 能源接口板
  （RS485 ×4 / CAN ×2 / 以太网 ×2 / 4-20mA 采集 ×8）。
- **故障注入**：电源时序可控（上电/断电斜坡 1ms–10s 可编程）、线路断连
  继电器矩阵（RS485/CAN/ETH 逐路可断）、EMC 注入（IEC 61000-4-2 ESD、
  4-3 辐射场强）、GPS 时钟断源/回拨。
- **验证矩阵**：对应 VRF-005 campaign（A/B 断电恢复 / 服务混沌 / 网络故障 /
  恶意 Agent 拒绝）在真机回放。
- 状态：**BLOCKED（无 HIL 机架）**；本规格作为采购/搭建输入冻结。

## 2. D2000 制造流程规格（冻结）

- **烧录**：工厂产线 UEFI 烧录 → 首次开机测量（TPM 平台寄存器）+ 设备身份
  密钥预置（见 §3）→ 功能自检（GPIO/RS485/CAN/ETH 回环）→ 贴标序列号。
- **验收**：产线自检报告（每板 sha256 清单）+ 抽样 EMC（每批次 3%）；
  出厂固件 = 当前 evidence 链冻结版本（防降级见 CRY-006）。
- 状态：**BLOCKED（无制造设施）**；流程规格冻结供产线启用。

## 3. 设备身份/密钥预置规格（冻结）

- **身份锚**：TPM EK（出厂预置）+ 设备序列号（烧录到 UEFI 变量，构建期
  注入模式见 BOOT-001 EXPECTED_DISK_GUID）；AK 由 EK 派生（CRY-004
  `from_identity_seed`——跨重启锚定设备身份，host 已验证）。
- **密钥分层**：UEFI 签名密钥（离线 CA）→ BootInfo 验签（Ed25519）→
  设备 AK（TPM 保护）→ 运行时代理密钥（seal 于 TPM，CRY-003）。
- **预置流程**：产线注入 EK 证书 + 设备证书签发；云侧注册表登记公钥。
- 状态：**BLOCKED（无产线）**；方案依赖的 host 侧验证（CRY-004 同 seed
  公钥稳定 + 签名互验）已 PASS。
