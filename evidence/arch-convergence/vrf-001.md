# VRF-001：真实 fuzz harness（S5）

## 交付

1. **libFuzzer harness 源码**（`fuzz/`，cargo-fuzz 标准结构，6 面）：
   - `fuzz_boot_protocol`：BootInfo::decode
   - `fuzz_ipc_wire`：el0::decode_frame
   - `fuzz_modbus_rtu`：ModbusFrame::decode
   - `fuzz_iec104`：apdu::Apdu::decode
   - `fuzz_elf_loader`：LoadedElf::parse（含 W^X 校验）
   - `fuzz_gguf_loader`：GgufHeader::parse + GgufMetadata::parse
   - 每面附语料种子（`fuzz/corpus/<target>/`）。

2. **stable 可运行 driver**（`cargo xtask fuzz <target> <iters>`）：
   确定性 PRNG 变异（翻转/截断/插入/加减）+ catch_unwind 崩溃检测——
   sandbox 无 clang/nightly rustc（libFuzzer 实际执行的外部依赖）。
