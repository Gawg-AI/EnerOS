# VRF-007：SBOM 生成校验 / 签名 provenance / 发布验证器（S5）

## 机制（全部从 evidence 计算，禁止硬编码 Passed）

- **SBOM 生成**：`cargo xtask release sbom --profile <id> --artifact <file>
  --cyclonedx <json> --spdx <json>`——从 cargo 图 + profile 闭包计算
  CycloneDX 1.6 / SPDX 2.3（purl、许可证来自 cargo metadata）。
- **发布验证器**：`cargo xtask release verify-sbom`——逐项比对计算：
  - CycloneDX metadata artifact digest == 实际产物 sha256（`--artifact`）；
  - `eneros:profile` / `eneros:profile-audit-sha256` /
    `eneros:forbidden-policy-sha256` 属性绑定 == 审计文件哈希（evidence）；
  - components purl 集合 == profile 闭包包集合（`validate_packages`）；
  - 每组件许可证非空且 purl 唯一；
  - SPDX creationInfo 绑定 / 文件哈希校验。
- **硬编码检查**：`xtask/src/sbom.rs` grep `Passed`/`Ok()` 无硬编码通过
  分支（HARDCODE_SCAN_DONE 零命中）——所有判定为错误返回或计算比较。
- **许可证证据**：`product/closure/binary-boms.json` 每包 license 字段来自
  cargo metadata（evidence 计算，非手工标注）。
