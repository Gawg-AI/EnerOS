## 2. WP-46.1 决策点：串口验证路径三选一（实测定夺）

执行前先实测 `qemu-system-aarch64 -device help`（方案 a 的可行性）：

```
$ qemu-system-aarch64 -device help 2>/dev/null | grep -iE "pl011|uart|serial" | grep -v "^name \"[0-9a-z]*(s|q|w|m)[0-9]*\", bus SSI"
name "pci-serial", bus PCI
name "pci-serial-2x", bus PCI
name "usb-serial", bus usb-bus
name "virtconsole", bus virtio-serial-bus
...
（429 设备全列出，无 pl011/uart 可加设备；virt 机内建单 UART、仅 -serial/chardev 映射）
```

**结论：落方案 b**——QEMU virt 无法添加第二个 PL011（virtio-serial-port / pci-serial 非 PL011 且 `Pl011UartHw` 驱动不兼容；驱动按 PL011 MMIO 寄存器编程）。Serial 工厂照常实现（真机/板卡 bring-up 时 root 移交 PL011 MMIO），验证路径取 host 级独立 peer（46.5 如实分级 `PENDING`，绝不把 host 级冒充 L2/Hardware）。

## 3. 实施内容（文件清单内逐项）

### 3.1 `crates/drivers/net/src/eth_frame.rs` — 802.1Q VLAN 支持
- `TPID_8021Q` / `ETH_HDR_LEN(14)` / `VLAN_HDR_LEN(18)` / `VlanTag{tci}`；
- `header_info(frame) -> Option<(ether_type_off, Option<VlanTag>)>`（无 VLAN→12，802.1Q→16；帧过短/标签残缺→None，fail-closed 不猜）；
- `net_ether_type` / `payload_offset`（VLAN 感知载荷偏移）；
- `encode_vlan(frame, tci)`（TPID+TCI 插于 src 后；已标记/过短→None，不二次嵌套）。
- 新增 7 条测试。

### 3.2 `crates/protocols/protocol-services/src/net_transport.rs` — 统一传输工厂（46.1.1/46.1.3）
- `NetStack<D: NetDevice>`：单一 NIC 上的 smoltcp `NetworkInterface`（Tcp/Udp/Raw 共用）；
- `NetTransportFactory<D>`：`TransportFactory` seam，三工族开放——
  - **Tcp**：open 完成握手，本地端口派生与 45 卷 `SmoltcpTcpTransport` 一致（地址字节和 %10000 + 40000；QEMU 证据端口不变），收发轮询语义（2000 tick 握手/发送、recv_timeout tick 接收）保持；
  - **Udp**：open 即 bind（peer 派生确定性本地端口），send_to/recv_from；
  - **RawEthernet**：设备直通帧收发（`iface.device.device`、virtio 头已由驱动处理），open 校验 MAC 格式/MTU 上限（fail-closed）；EtherType 过滤属 codec（sv_rx/goose_rx）。
  - Serial → `Err(Unsupported)`（单命令多工厂）；`build_net_transport` API 不变（返回 `NetTransport = NetStack<NetDriver>`）→ svc-modbus-tcp 零改动编译。
- `SerialTransportFactory<H: UartHw + 'static>`：把 UartHw（PL011 MMIO / host 仿真）包装为 `TransportFactory`（46.1.2）——
  - 单次移交语义（`Option<H>`，一个串口链一个传输独占；二次 open fail-closed）；
  - open 即 8N1 配置 + DE/RE 归收（B1 强约束，不隐藏硬件配置）；
  - `Rs485RtuTransport`（modbus-rtu 死代码原地复用、不重写）成帧（3.5 字符间隔）。
- `parse_mac`（12 位 hex / 冒号分隔）。
- 测试 15 条：三工厂正负例全覆盖（Unsupported fail-closed / 坏 peer / 坏 MAC / 超 MTU / recv 超时 / UDP 注入帧正例（合法检验和的 IPv4+UDP 帧回环）/ Raw VLAN+无 VLAN 帧直通 / Serial MockUartHw 环回成帧 + 超长帧前缀 256B 丢弃仅留尾部 44B）。

### 3.3 `crates/protocols/iec61850-sv/src/sv_rx.rs` — VLAN 感知解头（46.1.3）

## 4. DoD 自证

1. **三工厂各有正负例**：
   - Tcp：supports 正确；空/坏 peer→ConnectFailed；不可达→有界轮询后 ConnectFailed（不挂死）；
