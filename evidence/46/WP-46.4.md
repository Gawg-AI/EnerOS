## 1. 已完成项（测试先行）

### 1.1 mqtt keepalive（`client.rs`）
- 新增 `last_activity_ms` 字段（connect 成功/活动置位）；`poll(now_ms)` 现在**真实消费
  now_ms**：空闲 ≥ keep_alive_ms → 自动 `ping()`（PINGREQ/PINGRESP 有界同步）→ 刷新
  活动时间。锚点 `client.rs:493 poll 未消费 now_ms` 已闭环。
- 测试 `keepalive_poll_sends_pingreq_after_keep_alive_interval`：阈值内 0 发送；
  超阈值 PINGREQ（0xC0 0x00）+ 活动刷新。mqtt 55 测试全绿。

### 1.2 goose confRev（`goose_rx.rs` + `plugin.rs`）
- `GoosePdu` 新增 `conf_rev: u32`；`decode_pdu` 解码 0x88 字段（不再跳过；
  `TAG_CONF_REF`）。锚点「RX codec 暂不解码 confRev」已闭环。
- 插件新增 `conf_rev_mismatches` 计数 + `conf_rev_mismatches()` 探针：逐帧与
  `expected_conf_rev` 比对，不符 → 计数 + 降级（变更告警，不吞帧）。
- 测试：rx 解码（confRev=7 帧）→ `pdu.conf_rev==7`；插件联动（期望 1 收 7 → mismatch=1
  + Degraded）。goose（net）54 测试全绿。

### 1.3 goose VLAN 802.1Q TX（`goose_tx.rs` + `plugin.rs`）
- `GooseControlBlock` 新增 `vlan_id: Option<u16>`；`build_frame` 配置 vlan_id →
  src 后插 TPID(0x8100)+TCI（EtherType 移位至 16；与 46.1 rx 侧 `ether_type_offset`
  判定对称）。
- 插件 `KNOWN_KEYS += "vlan_id"`；解析（1..=4094 边界；越界 InvalidConfig）。
- 测试：配置 vlan_id=42 → 帧 [12..16]==0x8100+42、EtherType 于 16；未配置 → 无标签。
  （RX 侧 VLAN 解析已在 WP-46.1 闭环；此处补 TX 侧。）
