   §5.3）：`master.poll` 对 StartDtPending（STARTDT_ACT 已发未收 STARTDT_CON）
   空闲超 t1 → `drop_device`（关传输+清设备+清调度）→ `t1_timeout_count` 计数，
   适配器下一次 poll 自动重连（自愈）。插件 `KNOWN_KEYS += "t1_timeout_ms"` +
   解析传参；config-bundle protocol.rs 键同步 + configs/protocol-iec104.toml。
   - 测试 `test_t1_timeout_drops_startdt_pending_and_reconnect`（10s<15s 不断链；
     20s>15s 断链+计数；重连可行）。
2. **设点类 ASDU C_SE_NA(48)/C_SE_NC(50)**：共享 codec（iec104-slave）TypeId/
   IoValue/encode/decode（C_SE：值 + QDS（bit0=S/E=执行））；master
   `send_setpoint_normalized/float`（COT=Activation）；`handle_i_format`
   SetpointNormalized|SetpointFloat 确认臂。
   - 向量测试：-1234 → 2E FB + QDS=00；3.5f32 → 00 00 60 40 + QDS=00（手写向量
     按 IEC 60870-5-101 C_SE_NA_1/C_SE_NC_1 标准对象结构推导，注释登记）。
3. **C_SC 系**：主站 `send_single_command`/`send_double_command` 已存在
   （前卷），46.4 复核确认（TI=45/46 编解码已有）。
4. **M_ST(5)/M_BO(7) 步位置/比特串**：共享 codec TypeId/IoValue/encode/decode
   （M_ST：VTI 1B 低 3 位步值+高 5 位品质；M_BO：BS32 LE + QDS）；master
   `handle_i_format` 数据臂（StepPosition|Bitstring）→ latest_values。
   - 向量测试：VTI=0x05 roundtrip + 字节断言；BS32=0x01020304 → 04 03 02 01 + QDS
