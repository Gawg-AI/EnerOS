### 1.2 门禁（xtask，`cargo xtask audit all`/build/image 生效）
- `policy.rs`：`FrozenPolicy` 数据模型 + `load_frozen_policy`（schema 校验 + 豁免/allowlist 必须引用已冻结 crate 的防钻空校验）+ 纯函数
  `gate_frozen_release_closure`（R1：冻结 crate 进 release 依赖闭包且非豁免 → FAIL）与
  `gate_frozen_dependencies`（R2：非冻结 crate 声明依赖冻结 crate 且不在 allowlist → FAIL）。
- `main.rs::audit_profile`（release 类）：加载 frozen 策略 → R1 用 audit 闭包 reached 集合、R2 用 cargo metadata resolve 边（过滤 from=workspace 非冻结成员）→ violations。
