# TPM 2.0 集成设计文档 (v0.159.0)

> **版本**：v0.159.0  
> **状态**：已实现  
> **依赖**：v0.158.0 国密硬件加速

## 1. 概述

本模块集成 TPM 2.0 芯片驱动，实现硬件密钥管理和 PCR（平台配置寄存器）度量，为 v0.160.0 Secure Boot 提供可信根。

### 1.1 设计目标

- **硬件信任根**：TPM 提供不可导出的密钥保护
- **平台完整性度量**：PCR 记录启动链各阶段状态
- **远程证明**：支持 Quote 生成，供远程验证方验证
- **等保合规**：满足等保 2.0 三级"可信验证"要求

## 3. PCR 分配策略

| PCR | 用途 | 度量内容 |
|-----|------|---------|
| 0 | 启动代码 | Bootloader/Firmware |
| 1 | 内核配置 | 设备树/启动参数 |
| 2 | 用户态 | 运行时/驱动 |
| 4 | 内核镜像 | Kernel binary |
| 7 | Secure Boot | 安全启动策略 |
| 8+ | 应用 | Agent 组件 |

## 4. 密钥层次

```
EK (Endorsement Key) — 硬件内置，不可导出
 └── SRK (Storage Root Key) — 存储密钥根
      ├── AK (Attestation Key) — 证明密钥
      └── Agent Keys — Agent 签名密钥
```

## 5. 启动度量流程

1. TPM 初始化（TPM2_Startup）
2. PCR 0: 度量 Bootloader
3. PCR 4: 度量内核镜像
4. PCR 1: 度量内核配置/设备树
5. PCR 2: 度量用户态组件
6. PCR 7: 度量 Secure Boot 策略
7. 定期完整性验证

## 6. 错误处理

| 错误 | 处理策略 |
|------|---------|
| TpmNotPresent | 降级到软件 TSS |
| TpmTimeout | 重试 3 次后报错 |
| PcrMismatch | 触发安全告警，拒绝启动 |
| AuthFailed | 锁定 TPM（防暴力破解） |
