# EnerOS 系统威胁模型（STRIDE）

> 版本：v0.257.0（RC-3a，D3 安全评审准备）
> 依据：蓝图/14-阶段D-商用验收闸门.md D3「安全文档成册」；
> 范围：EnerOS 全系统（启动链/内核/用户态/协议面/安全面/运维面）。

## 1. 系统边界与信任假设

```
┌────────────────────────────────────────────────────────┐
│  物理边界（设备）                                        │
│  ┌─────────┐  ┌──────────┐  ┌──────────┐  ┌─────────┐  │
│  │UEFI固件 │→│boot-manager│→│  seL4     │→│ root-task│  │
│  │(厂商)   │  │(自研签名)  │  │(形式化验证)│  │ +EL0服务 │  │
│  └─────────┘  └──────────┘  └──────────┘  └─────────┘  │
│       ↓ 验签链            ↓ 内存隔离       ↓ 受限能力     │
│  ┌──────────────────────────────────────────────────┐   │
│  │ 协议面（Modbus/IEC104/IEC61850/MQTT/DDS）          │   │
│  │ 安全面（SM2/3/4、OTA、attestation、PKI）           │   │
│  │ Agent 面（AI 决策链、市场结算、账户）               │   │
│  │ 运维面（mgmt-api、遥测、日志、crash-dump）          │   │
│  └──────────────────────────────────────────────────┘   │
└────────────────────────────────────────────────────────┘
```

**信任假设**（攻击者模型）：
- A1 攻击者无物理写访问（外壳防拆、焊盘胶封）；有物理访问时视为完全失守
- A2 UEFI 固件由板卡厂商签名（信任根链起点；EnerOS 从 boot-manager 起自持）
- A3 攻击者可控制**外部网络**（协议对端、broker、主站侧）；不可控设备内部总线
- A4 攻击者可注入**恶意 ELF 插件**（签名校验失败必须拒绝）
- A5 攻击者不可获取设备私钥（HSM/SE/安全存储）；可获取证书/公钥

## 2. STRIDE 威胁清单

### S — Spoofing（身份伪装）

| # | 威胁 | 影响面 | 缓解 | 状态 |
|---|---|---|---|---|
| S1 | 伪装可信 OTA 包 | OTA 链 | SM2 验签（secure-boot） | ✅ 已实现 |
| S2 | 伪装 EL0 服务/插件 | Agent 链 | 签名 ELF + W^X 校验 | ✅ 已实现 |
| S3 | 伪装 MQTT broker / TLS 对端 | 通信链 | TLS 双向认证（mtls） | ✅ 已实现（mtls-design） |
| S4 | 伪装 IEC104 主站 | 协议链 | 可选鉴权（IEC62351） | ✅ 已实现（iec62351） |
| S5 | 伪装 mgmt-api 管理员 | 运维链 | SM2 签名 Token（v0.239） | ✅ 已实现 |
| S6 | 伪装 attestation 验证方 | 证明链 | 挑战-响应 + 签名 | ✅ 已实现 |

### T — Tampering（篡改）

| # | 威胁 | 影响面 | 缓解 | 状态 |

| T1 | 篡改启动镜像 | 启动链 | 安全启动验签链 | ✅ 已实现 |
| T2 | 篡改运行中内存 | 运行时 | seL4 内存隔离 + W^X | ✅ 已实现 |
| T3 | 篡改遥测/日志 | 运维链 | 审计链（audit-chain）+ 哈希链 | ✅ 已实现 |
| T4 | 篡改账本/结算 | 交易链 | 定点记账 + 审计 + 对账 | ✅ 已实现 |
| T5 | 篡改协议帧 | 协议链 | CRC + 序号校验 + 重组校验 | ✅ 已实现 |
| T6 | 篡改性能基线证据 | 工程链 | ed25519 签名（v0.251） | ✅ 已实现 |

## 3. 残余风险（需外部评审确认）

| 风险 | 说明 | 处置 |
|---|---|---|
| 自研国密实现未经独立评审 | SM2/SM3/SM4 自研（product_allowed=false） | D3 密码学独立评审（外部） |
| UEFI 固件信任 | 依赖板卡厂商签名链 | 采购评审 + 固件版本锁定 |
| 侧信道物理攻击 | 未做功耗/电磁分析测试 | 视威胁模型补充（低优先） |
| 渗透测试未执行 | pentest 规则库就绪但未跑真机 | D3 渗透测试（外部） |
