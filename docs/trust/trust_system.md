# EnerOS Agent 信誉体系设计 (v0.168.0)

> **子系统**：crates/agents/trust（eneros-trust）  
> **Phase 定位**：P3-K Agent 信任与认证首版本  
> **等保关联**：等保 2.0 三级"访问控制"核心

---

## 1. 概述

Agent 信誉体系基于行为历史动态计算 Trust Score（0-1000），支持信誉分级与自动降级。高信任 Agent 获得更多资源/能力，低信任 Agent 被限制，极低信任 Agent 被封禁。

## 2. 架构

```text
┌─────────────────────────────────────────────────────┐
│  eneros-trust (v0.168.0)                            │
│                                                     │
│  types.rs ──── 核心类型（AgentId/TrustScore/Grade） │
│  scoring.rs ── 评分规则（7 种行为 → 分数变化）      │
│  history.rs ── 行为历史（记录 + 趋势）              │
│  adjuster.rs ─ 动态调整（时间衰减 + 手动）          │
│  manager.rs ── TrustSystem 实现（统一管理）         │
└─────────────────────────────────────────────────────┘
```

## 3. 信誉等级

| 等级 | 分数范围 | 权限 |
|------|---------|------|
| Platinum（白金） | 900-1000 | 全部能力解锁 |
| Gold（金） | 700-899 | 标准能力 |
| Silver（银） | 400-699 | 基础能力（初始 500 分） |
| Bronze（铜） | 100-399 | 受限能力 |
| Blocked（封禁） | 0-99 | 所有能力禁用 |

## 4. 评分规则

| 行为类型 | 分数变化 | 说明 |
|---------|---------|------|
| TaskComplete | +5 | 成功完成任务 |
| TaskFailed | -3 | 任务失败 |
| Unauthorized | -50 | 越权访问 |
| MaliciousBehavior | -200 | 恶意操作 |
| Crash | -10 | Agent 崩溃 |
| Recovery | +2 | 成功恢复 |
| Cooperation | +3 | 协助其他 Agent |

修正规则：
- 正面行为失败 → 加分减半
- 负面行为成功 → 扣分加倍

## 5. 时间衰减（防刷分）

分数向初始分（500）回归：
- 高于 500 → 每周期缓慢下降
- 低于 500 → 每周期缓慢上升
- 默认：每 3600 时间单位衰减 1 分

## 6. 生命周期

```text
注册(500分) → 记录行为 → 分数变化 → 等级升降
                                        │
                              分数 < 100 → 封禁
                                        │
                              手动调整 → 恢复
```
