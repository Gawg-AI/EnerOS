## 结论

- **软件工程侧全部闸门绿**：G1/G5/G6/G7 核销；质量门禁 10 项全绿。
- **G2/G3/G4 BLOCKED 外部依赖**：真机浸泡（飞腾/鲲鹏硬件）、四类真实
  对端互操作、独立密码评审+渗透测试——均需外部资源，非软件工程可
  自证。BLOCKED 项的**验证基础设施全部就绪**（执行器/框架/证据格式/
  报告器），资源到位即可一键执行闭环。
- **授权动作**：外部依赖项完成后重跑对应 RC 验收（soak72 + interop +
  密码评审），G1-G7 全绿即正式打 tag v1.0.0。
