# 差分更新设计文档 (v0.161.0)

> **版本**：v0.161.0  
> **状态**：已实现  
> **依赖**：v0.111.0 模型热更新基础

## 1. 概述

实现 LLM 模型差分更新，仅传输增量包，升级包体积减少 >= 90%，带回滚保护。

## 2. 架构

```
OTA 服务器
    │ 差分包 (DiffPatch)
    ▼
边缘设备 OtaManager
    ├── 1. 创建快照 (SnapshotManager)
    ├── 2. 验证补丁 (verify_patch)
    ├── 3. 应用差分 (apply_patch)
    ├── 4. 验证哈希 (SM3)
    └── 5. 提交 / 回滚
```

## 3. 差分格式

指令序列：
- `0x00 + len`: COPY_PREFIX - 从旧数据开头复制 len 字节
- `0x01 + len + data`: INSERT - 插入 len 字节新数据
- `0x02 + len`: COPY_SUFFIX - 从旧数据末尾复制 len 字节

## 4. 回滚保护

- 更新前自动创建快照
- 任何阶段失败自动回滚
- 快照数量限制（默认保留 5 个）
- 支持手动回滚到最近快照

## 5. 性能指标

| 指标 | 目标 |
|------|------|
| 差分包体积减少 | >= 90% |
| 差分应用时间 | < 10s (100MB) |
| 快照创建时间 | < 5s |
