# 灰度发布设计文档 (v0.162.0)

> **版本**：v0.162.0  
> **状态**：已实现  
> **依赖**：v0.161.0 差分更新

## 1. 概述

实现 OTA 灰度发布框架，支持按比例推送、分批验证、失败率超阈值自动暂停/回滚。

## 2. 灰度流程

```
阶段 1: 5% 设备 → 观察 5min → 失败率 < 5%?
    ↓ 是
阶段 2: 25% 设备 → 观察 10min → 失败率 < 5%?
    ↓ 是
阶段 3: 50% 设备 → 观察 10min → 失败率 < 5%?
    ↓ 是
阶段 4: 100% 设备 → 观察 5min → 完成
```

## 3. 自动止损

| 失败率 | 动作 |
|--------|------|
| <= 5% | 继续推进 |
| > 5% 且 <= 10% | 自动暂停，等待人工决策 |
| > 10% | 自动回滚 |

## 4. 核心组件

- `CanaryPolicy`: 灰度策略（阶段 + 阈值）
- `CanaryEngine`: 灰度引擎（启动/监控/推进/暂停/回滚）
- `CanaryDeployment`: 灰度实例（状态 + 阶段进度）
- `StageStatus`: 阶段统计（推送/成功/失败）

## 5. 测试

- 单元测试：58 项全部通过
