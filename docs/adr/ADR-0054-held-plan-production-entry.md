# ADR-0054：站点计划由 dispatch 持有，按 Saga 事件先持久后执行

- 状态：实施决策已接受，生产接线与验收尚未完成（2026-09-17）
- 关联：ADR-0052 激活条件 2b、ADR-0046、DEC-70-13、CORE-70-R10。

生产批入口选现有 `svc-control-dispatch` 的可信计划入口。它必须在独立认证、
全批绑定与合同预检之后持久化完整计划、证书验证材料、输入引用、编译结果和
逐命令状态，再返回“已持有”。同一进程负责有界 tick、查询和恢复，复用
`BatchSaga`、唯一 Gateway 与设备读写通道；不新增调度进程，也不把调用者
重复提交同一计划当作未来步骤的持有实现。本决策满足 ADR-0052 的批入口裁决
前置；只有接入这个真实入口所需的行为解冻，不能以本文件宣称生产已激活。

每站最多一个活跃计划与一个待切换计划；沿用 DEC-70-13 每批 8 intents 上限。
容量满明确拒绝，重复身份返回已有状态；未解决的未知效果隔离资源，不能因
后继成功、优先级更高或重新启动而变成成功或允许新写。原始计划、每意图终态、
未执行原因与实际回读必须可查询，批级“受理”与“全部确认”分开。

持有状态建立在 `durable-state` 的双槽代次与 CRC 上，使用独立登记的 DataRegion，
不移动已有介质坐标。每个 Saga 事件落盘成功后才能推进内存状态；Executing 必须
先于外部写持久化。事件追加失败停止推进。恢复读取完整旧代或新代，不猜补尾，
未知格式/坏状态拒载；只有明确空白区域可作为首次启动。旧镜像不消费新计划
区域，因此存在未清算计划时禁止回退到旧镜像正常控制，须先进入受控恢复。

单调时间跨重启不连续，不能将旧 valid_from/valid_until 重新解释为未来窗口。
恢复优先对已经发送或可能发送的命令做独立只读对账；原未发步骤显式终止，
余下需求须用新快照生成新候选并重新认证，不续用旧证书。新旧候选的关联保留
在诊断中。没有可靠回读或双重证据时维持人工状态，绝不自动重发。

持有期间须保留证书引用的冻结输入与事件，释放或到期后解除持有，避免现有
只收紧不释放的 offset 接口永久阻塞回收。驱动来自周期 tick，不能依赖 worker
恰好提出新计划；worker 无动作、不可用或冷却期间，已有计划也必须得到到期/
撤销判定。实时输入无效时只对账、撤销或等待，不发新控制命令。

当前包络有效期仍是快照产出后 30 秒。不能为容纳现有 4×15 秒配置而放宽这个
安全事实；接入时须拒绝超过证书有效期的批，或通过显式的新快照/新认证拆批。
目标侧四步正常演示的时域与调度耗时须实测冻结。`assets=2`、`CERTIFIED` 和
`DEFERRED` 词形都不能代替逐意图执行、部分失败和重启恢复证据。
