# 信创认证申请指南

## 概述

EnerOS 信创认证（信息技术应用创新）准备文档，对应 v0.170.0 Phase 3 出口标准。

## 认证范围

| 序号 | 检查项 | 关联版本 | 状态 |
|------|--------|----------|------|
| 1 | 自研内核 | v0.127.0~v0.157.0 | ✅ 通过 |
| 2 | 国产 CPU 支持 | v0.145.0/v0.146.0 | ✅ 通过 |
| 3 | 国密算法 (SM2/SM3/SM4) | v0.158.0 | ✅ 通过 |
| 4 | TPM 2.0 | v0.159.0 | ✅ 通过 |
| 5 | Secure Boot | v0.160.0 | ✅ 通过 |
| 6 | 纯 Rust 实现 | v0.170.0 | ✅ 通过 |
| 7 | 无国外闭源组件 | v0.170.0 | ✅ 通过 |

## 申请流程

1. **技术准备**：完成上述 7 项技术指标验证（本模块自动化检查）
2. **材料准备**：编写产品说明书、技术白皮书、源代码审计报告
3. **提交申请**：向工信部信创产品目录管理机构提交申请
4. **测评验证**：配合授权测评机构进行产品检测
5. **目录入围**：通过测评后进入信创产品目录

## 技术亮点

- 完全自研微内核，无 Linux/FreeBSD 等外部内核依赖
- 飞腾 D2000 + 鲲鹏 920 双国产 CPU 平台支持
- 国密 SM2/SM3/SM4 全套算法纯 Rust 实现
- 零第三方依赖，供应链完全自主可控
- Rust 语言内存安全，消除缓冲区溢出等安全隐患

## 注意事项

- 信创认证需产品化后申请，当前阶段为技术准备度验证
- 认证有效期通常为 3 年，需定期复审
- 产品重大变更需重新申请认证
